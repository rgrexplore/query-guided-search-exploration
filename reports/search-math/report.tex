\vspace{13mm}
This report develops the three methods from the same score and the same retrieval task.
It explains what is built before a query, what is touched during a query, and where each
method can lose recall. Every general cost formula uses named parameters. Small numerical
examples make the formulas concrete; measured results are identified separately.
\vfill
\textbf{Reading order.} Start with the four-bit example and shared pipeline. Each method then
has its own data layout, pseudocode, operation count, latency model, and memory calculation.
The statistical section explains what can and cannot be inferred about recall. The final
section collects the formulas for comparison under a RAM limit.

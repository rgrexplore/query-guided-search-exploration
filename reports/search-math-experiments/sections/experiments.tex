\section{Experiments}
\subsection{Setup}
\begin{enumerate}
\item \textbf{Data.} One million MS MARCO documents~\cite{msmarco}, 200 queries, and existing Nomic embeddings~\cite{nomic}. Every run uses the same arrays, values and query rows.
\item \textbf{Score.} Documents have 256 sign bits; queries have 256 float values. The reference is the exact best 100 IDs. Returning 99 on average gives 99\% recall.
\item \textbf{Settings.} Vary clusters, probes, B's leaf size and branch budget, and C's key width and lookup limit. Keep the full score unchanged.
\item \textbf{Probes.} For each cluster count, find where A reaches 80\%, 90\%, 95\% and 99\% recall. Include opening all clusters. Give A, B and C these same choices.
\item \textbf{Machine.} Apple M5 Max, 128 GiB physical RAM, one CPU thread, and a 32 GB limit per process.
\item \textbf{Runs.} Test 256 settings. Each searches all 200 queries twice. Repeat the fastest qualifying settings in three processes on those same queries.
\item \textbf{Time.} Report the median. Include cluster selection and search; exclude index building and embedding generation.
\item \textbf{Input check.} Compare file hashes before and after the runs. No input array changed.
\end{enumerate}

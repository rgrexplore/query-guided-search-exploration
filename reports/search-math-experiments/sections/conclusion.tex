\section{Limitations and Next steps}
\begin{enumerate}
\item Only one unchanged document collection and query set were tested. Every method used the same score, reference IDs, RAM limit and CPU thread count.
\item The chosen settings were fastest within this tested range. They do not prove the best possible implementation.
\item Scores, mask reads and key lookups have different time costs. Memory access, code and hardware affect those costs.
\item The ideal bit pattern does not tell us how many branches or keys are needed. Check those counts on the actual data.
\item Next: expand the parameter range or improve a measured expensive operation on the same benchmark. Report any later change of model, documents or queries as a separate comparison.
\end{enumerate}

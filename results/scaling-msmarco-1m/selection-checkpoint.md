# Frozen development choices

[selections.json](selections.json) was saved after all 231 development cases completed and before
running evaluation. Each pool has a 95% and 99% candidate-recall target. A shared budget is
measured once in evaluation when both targets choose it.

The file includes the development input hashes and selection source hash. The final report will
show achieved evaluation recall, including any target misses. Choices stay unchanged after this
checkpoint.

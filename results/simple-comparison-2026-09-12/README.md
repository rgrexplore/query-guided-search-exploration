# Historical query-shape experiment

This experiment uses one generated document collection but changes query magnitudes across
three examples. It answers a different question from varying index parameters on an unchanged
document-and-query benchmark. It is not used in the current report's comparisons or conclusions.

The current benchmark is `results/fixed-data-comparison-2026-09-12/`. This folder is retained
as an experimental record; its raw cases are in `runs/cases.zip`. The original generated
arrays remain local and are excluded from Git.
